# interpuls.no

Statisk nettside for Interpuls. Publiseres automatisk av Netlify ved hver endring i denne mappen.

- `index.html` – hele nettsiden (tekst og program ligger i JavaScript-objektene `T`, `PROGRAM`, `PEOPLE` osv.)
- `img/` – bilder
- `netlify.toml` – innstillinger og videresending fra gamle adresser
- Programslipp: sett `RELEASED_2027 = true` i `index.html`
